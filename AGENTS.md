# 桌面便利贴

- Read `README.md`, `VERSIONING.md` and `CHANGELOG.md` before maintaining this project.
- Use this repository only for this project. Preserve other uncommitted changes and the user's index.
- `pubspec.yaml` 的 `version`，当前 `1.4.1+9`。标签使用 `v1.4.1`，`+9` 为构建号；不要另设重复的 VERSION 文件。
- 便签正文、计划、勾选状态、提醒和外观设置要保持兼容。安装包必须由正式入口构建，个人便签和退出日志不进 Git。
- Make meaningful commits at verified milestones; stage an explicit file list. Keep changelog and version metadata consistent.
- Preserve existing tags and history. Source pushes do not by themselves authorize a new deployment or installation-package release.
