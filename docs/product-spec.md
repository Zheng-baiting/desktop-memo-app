# 桌面便利贴产品规格（MVP）

## 1. 产品目标

为容易遗忘事情的用户提供一个随手可写、持续可见、到时主动提醒的跨平台便利贴工具。产品以低操作成本为首要目标：打开即写、写完即存、需要时主动提醒。

## 2. 首期平台

- 桌面：Windows、macOS、Linux
- 移动：Android、iOS
- 网页端不进入首期范围

各设备独立运行、独立保存、独立设置提醒；首期不提供账号、联网或跨设备同步。

## 3. 核心体验

### 多便利贴

- 用户可以同时创建多张便利贴。
- 每张便利贴拥有标题、正文、主题、颜色、创建时间、修改时间和可选提醒时间。
- 编辑内容自动保存，不依赖手动保存按钮。
- 支持按创建时间、修改时间和提醒时间排序。

### 桌面交互

- 便利贴窗口可以在屏幕上自由拖拽和调整大小。
- 拖到屏幕边缘后自动吸附并收起，仅保留可识别的小标签。
- 鼠标移入或点击标签时展开；鼠标离开后可延时收起。
- 支持置顶与普通窗口模式切换。
- 通过可自定义的全局快捷键快速新建便利贴。
- 关闭主界面后可留在系统托盘，以便快捷键和提醒继续工作。

### 移动交互

- 使用便利贴卡片列表管理多条记录。
- 支持桌面小组件或系统快捷入口快速新建。
- 不模拟桌面端的屏幕边缘吸附行为。

### 提醒

- 支持单次提醒和常用重复提醒。
- 桌面端提醒方式：系统通知、小弹窗、语音朗读、便利贴窗口抖动。
- 移动端提醒方式：系统通知、提示音、振动；应用处于活跃状态时可语音朗读。
- 各提醒方式可单独开关，并服从操作系统权限和勿扰模式。
- 若系统不允许后台语音朗读，使用系统通知文字与提示音作为可靠后备。

### 外观

- 纸质便利贴主题：暖色、轻质感、可选便签颜色。
- 现代半透明主题：简洁、低干扰、适合长期停留桌面。
- 用户可以随时切换主题，不影响已有内容。
- 动画需支持“减少动态效果”系统设置。

## 4. 本地数据与隐私

- 内容默认只保存在当前设备。
- 无账号、无遥测、无广告、无网络依赖。
- 使用本地数据库和原子事务，避免编辑或异常退出导致数据丢失。
- 提供本地导出与导入，便于用户自行备份。

## 5. MVP 验收标准

1. 五个平台共享同一套核心业务代码，并能分别构建。
2. 用户可以创建、编辑、删除和查找多张便利贴。
3. 关闭并重新打开应用后，内容、位置、尺寸、主题和提醒仍被保留。
4. 桌面便利贴可拖拽；靠近屏幕边缘时正确吸附、收起和展开。
5. 桌面端在应用不处于前台时，全局快捷键仍可创建新便利贴。
6. 提醒在获得系统权限后按设定时间触发，并至少显示系统通知。
7. 纸质与半透明主题均具备可读性，切换后内容不变。
8. 所有用户数据均保持在当前设备，除非用户主动执行导出。

## 6. 首期不包含

- 登录、云同步和多人协作
- 网页版
- AI 内容生成
- 商店发布和自动更新服务
