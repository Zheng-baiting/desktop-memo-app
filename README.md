# Desktop Memo App / 桌面便利贴

纸质便利贴风格的 Flutter 应用，面向容易忘事的人。备忘录保存在设备本地，不登录、不跨设备同步。

## 当前完成情况

桌面端现在使用**独立的无边框便利贴窗口**，不再局限于管理窗口中的画布。纸张使用 18 像素柔和圆角；空白处拖动原生窗口，拖动时抬到其他便利贴上方，靠近屏幕工作区边缘收成标签，点击标签展开。便利贴是普通桌面窗口，不会强行盖住所有其他软件，也不是嵌入系统壁纸层。

贴边后收成四角圆润的小标签。鼠标悬停自动滑出，移开约半秒后自动收回；编辑标题/正文、设置提醒、拖拽或处理到点提醒时保持展开。拖离边缘后退出自动收纳模式。悬停不会主动抢键盘焦点，展开/收起遵循系统减少动画设置。

收起位置按系统实际接受的窗口尺寸校正，标签沿对应屏幕边缘对齐；即使系统强制窗口比标签更宽，左右标签仍保持相同的可见尺寸和边缘留白。每次切换只调整一次原生尺寸，必要时校正位置，不逐帧缩放系统窗口。

打开软件直接恢复桌面上的小便利贴，不再默认弹出大管理窗口；没有任何便利贴时显示管理页，由用户新建。每张贴底部的齿轮打开同尺寸的纸质设置页，可管理本机开机自启动、进入本张提醒设置、查看全局新建快捷键，以及保存并退出整个应用。返回后标题和正文保持不变，设置期间不会自动贴边收起。

每张便利贴右上角的 × 是删除该张便签的唯一入口，先询问是否彻底删除；取消、关闭确认框都保留内容。确认“彻底删除”才从本地存档移除正文、计划、完成状态和提醒，不设回收站或撤销；+ 新建另一张。从任务栏关闭应用、托盘选择“保存并退出”或贴内设置退出时，会收齐每个窗口尚未发送的编辑并保存全部记录，保存成功才退出，下次打开恢复全部未删除的便签。系统关闭事件不会删除任何便签。提醒到期和计划结束也不会删除便签。

## 退出耗时诊断

桌面程序会在可执行文件旁的 `logs/exit-timing.jsonl` 写入本地退出诊断，不上传日志。每条记录包含 UTC 时间、临时会话编号、固定阶段名、开始/完成/失败/等待状态，以及毫秒耗时。仅用本次退出的顺序编号区分各张贴，不记录标题、正文、提醒内容、持久化 ID、异常文本或用户路径。当前日志达到约 256 KiB 时轮换，仅保留当前文件和一份 `.previous`。

`noteRequest` 记录便利贴设置页的退出请求，其中 `saveCurrentNote` 是当前贴保存，`sendExitRequest` 是向主进程发送退出请求。随后 `shutdown` 下的 `saveNote` 是逐张保存，`saveAll` 是写盘，`notifications` 是等待通知队列，`closeNotes` 是冻结编辑、再次保存末次输入并关闭所有子窗口，`tray` 是移除托盘，`closeWindows` 是退出主窗口。`elapsed_ms` 为阶段耗时，`total_ms` 为该会话自创建以来的耗时。等待超过两秒会继续写入 `waiting`；关闭子窗口超过五秒则保留主程序并提示重试，不会强杀或跳过保存。

窗口关闭可能直接终止记录日志的引擎，所以最后一条 `closeWindows/start` 表示已请求关闭，不等于关闭卡住，也不能据此算出进程完全退出的耗时。日志写入失败时跳过诊断，不改变保存或退出结果；安装目录只读时可能没有日志。

日志单测：`flutter test test/exit_timing_log_test.dart`。原生退出检查：`flutter run -d windows --release -t test/native_exit_smoke.dart`（两张内存临时贴，不使用真实备忘录）。看到 `NATIVE_EXIT_REQUEST` 后应在十秒内退出，必须从外部确认退出码为 0，不能仅以输出过该标记判断通过。添加 `--dart-define=DELETE_BEFORE_EXIT=true` 检查删除后立即退出；再添加 `--dart-define=EXIT_NOTE_COUNT=1` 检查删除最后一张后立即退出。检查后重新构建 `lib/main.dart`，不要使用测试入口作为正式版。

2026-10-14 修复了原生退出顺序：旧版直接结束消息循环，让子 Flutter 引擎留到静态对象析构时才销毁；本机两张临时贴复现退出请求后约 9.9 秒崩溃。现在先保存并关闭所有子引擎（包括已删除但仍在关闭中的窗口），再销毁主引擎，最后释放 COM。子窗口只注册窗口管理和屏幕信息插件，语音、托盘等只由主窗口加载。桌面快捷方式使用原生无控制台启动器，省去 PowerShell，仍请求原有独立启动任务；本机创建进程等待由约 725 毫秒降到 125 毫秒。这是本机单次测量，不代表完整窗口显示时间。

## 提醒限制

新增“每天重复”：选择开始日期/时间以及结束日期（含当天）。提醒后点击“今天已读”仅停止本次提示，保留下一天的同一时间；进入提醒设置选择“取消提醒”才停止整个循环。跨月和重启后仍保持原本的本地钟表时间，错过多天只补提醒一次，超过结束日期不再补提醒。旧便签的一次性和每10分钟行为保持兼容。

每日循环后续调度需要保持应用运行，电脑关机/休眠期间不能保证准时弹出。可在贴内设置启用登录自启动；本机已按用户要求启用，并核对启动入口与 Windows 启用状态。未通过重启或注销电脑验证实际登录过程。

已导入的逐日学习计划在同一张贴内按本地日期自动更新：标题为 `YYYY-MM-DD`，正文为该日的分钟日程。开始前显示第一天预览，结束后保留最后一天；不会同时创建数百个窗口。重启时直接显示当前日期的内容，系统通知使用对应提醒日期的计划，跨日旧窗口的延迟保存不会覆盖新一天。普通便签不受影响。逐日计划数据保存在原有本地偏好设置中。

逐日内容测试：`flutter test test/daily_plan_test.dart`；原生每日回归同时验证日期标题、内容更新和旧日期写入保护。

逐日计划的每个时间段带有 ✔ 按钮，点击后该行在 450 毫秒内渐变灰色并加删除线，再点撤销；系统减少动画开启时立即切换。完成状态由主窗口写盘，按日期和任务原文区分，重启后保留；修改后的新任务不会误继承旧任务的完成状态。普通便签仍可直接编辑正文。列表可滚动查看整天计划。

完成状态测试：`flutter test test/plan_checklist_test.dart`；原生每日回归另外验证主窗口保存、撤销和跨日隔离。本机学习计划设置为 2026-09-17 至 2027-03-16 每天 20:10，英语复习至 12 月 11 日、IE 优先备考至 12 月 29 日，Python/Agent 每天保留。

逐日计划可保存 `reminderTimes`（日期到 `HH:mm`）。非空日历是完整的提醒日期表，缺失日期表示休息；没有日历的旧便签仍按原时间每日重复。启动时只在当天计划的时间块内补提醒；休息日、午间长休息和学习结束后不会补弹。Windows任务 `DesktopMemo-StudyReminder-2010` 使用已获授权的普通用户权限，每天09:00执行日历检查；仅在学习日09:00–11:00或14:00–17:00启动未运行的程序。只有完成显示后才接收补提醒。Windows便签统一保存在用户文档目录的“桌面便利贴数据/notes.json”，不再以会被MSIX启动环境重定向的AppData作为主存储；首次迁移保留原内容，写入先落临时文件再替换。原生回归调用memoryOnly入口，不能读取或覆盖用户数据。任务名称沿用历史名称，实际时间以任务配置为准。

验证命令：`flutter test test/daily_reminder_test.dart`；Windows原生验证：`flutter run -d windows --release -t test/native_daily_smoke.dart`。后者使用内存便签，验证启动补提醒、独立窗口弹出、下一次时间、已读保留循环、取消及其他便签不变。测试后重新构建正式入口 `lib/main.dart`。

一次定时通知交给系统调度；实际送达取决于权限与系统设置。
Linux 没有插件提供的后台定时调度，必须保持应用运行。
持续提醒的后续调度、语音播报依赖应用进程；退出应用后不能保证持续播报。
取消/删除会尝试撤销对应系统通知，调度失败会提示，不能将静态分析通过视为已实际送达。

独立便利贴支持日期和时间选择、一次/每 10 分钟提醒、取消提醒、到点窗口提示和短暂晃动（尊重系统减少动画设置）。手机后台持续语音、自定义重复周期、跨平台/多屏实机测试，以及正式安装与签名仍待完善。系统通知是否实际显示、语音是否能听到仍需在目标设备上确认，原生回归不等于这些外部效果已验收。

桌面端的日期学习计划仅使用便利贴自己的窗口提示和语音，不新建系统通知；重排时取消该便签旧的系统通知。启动器直接启动便利贴可执行文件，不调用浏览器或 ChatGPT。普通便签的通知行为保持原设置。

Windows 独立运行：`scripts/install-independent-launch.ps1` 将桌面快捷方式接到同目录的 `memo_launcher.exe`，它使用 Windows Task Scheduler COM 请求当前用户既有的 `DesktopMemo-IndependentLaunch` 按需任务，不启动 PowerShell、不显示控制台。该任务由 Windows 启动正式程序，没有自动触发器、管理员权限或运行时限；重复请求会被忽略。任务已经存在且路径正确时，仅运行 `scripts/update-independent-shortcut.ps1` 更新快捷方式，不改动任务配置。每日学习日历检查仍请求同一任务。只有用户授权后才运行安装脚本。关闭请求启动的应用不会结束这个由 Windows 启动的便利贴进程。Windows 程序、启动器与托盘统一使用黄色卷角笑脸便利贴图标；桌面快捷方式直接读取随程序安装的 `memo-cartoon.ico`，更新时仅通知 Shell 刷新该快捷方式，避免继续读取旧的可执行文件图标缓存。

需要 Flutter 3.47 / Dart 3.13 或兼容版本，并安装目标平台编译工具。

```powershell
flutter pub get
flutter analyze
flutter test
flutter run -d windows
```

原生多窗口隔离回归（会显示两张临时贴并触发一条临时提醒）：

```powershell
flutter run -d windows --release -t test/native_smoke.dart
flutter run -d windows --release -t test/native_smoke.dart --dart-define=EMPTY_START=true
flutter run -d windows --release -t test/native_dock_smoke.dart
```

看到 `NATIVE_SMOKE_PASS` 表示通过；若命令仍在等待，按 q 结束。测试后交付前必须使用 `flutter build windows --release -t lib/main.dart` 重新生成正常程序，不要分发测试入口产物。

原生回归还检查管理窗口启动时隐藏、贴内设置能读取自启动状态，以及空列表启动保留空存档并显示管理页。测试不会切换系统自启动设置；真实登录后的启动行为仍需用户验收。

四边收纳回归使用四张临时贴，通过测试入口专用通道读取实际窗口和纸张的绘制边界，检查标签完全可见、距对应边缘 8 逻辑像素，并检查展开后再次收起的位置。测试时请把鼠标放在屏幕中部、远离临时贴，避免悬停阻止自动收起；成功输出 `NATIVE_DOCK_PASS`。
